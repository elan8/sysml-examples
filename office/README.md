# Office — minimal example

A **small SysML v2 structural example**: a desk workspace with wall power, laptop, monitor, mouse, and keyboard.

## Model

- **[office.sysml](office.sysml)** — package `Office`: part definitions (`Laptop`, `Monitor`, …), assembly `my_computer`, connections (HDMI, USB, power), and requirement `goodComputer` on the laptop.

This example is intentionally minimal compared to [timer](../timer/), [drone](../drone/), and [intersection](../intersection/); it has no separate long-form narrative.
