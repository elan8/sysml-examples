# Code Of Conduct

## Our Standard

We want this repository to be a welcoming place for learners and contributors of all experience levels. Treat others with respect, assume good intent, and keep feedback constructive and specific.

## Expected Behavior

- Be respectful and patient in discussions and reviews.
- Focus on the work, not on personal attributes or assumptions.
- Share criticism in a way that helps others improve the repository.
- Be open about uncertainty, tooling differences, and the limits of these examples.

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks.
- Dismissive or demeaning language toward learners or contributors.
- Bad-faith disruption, trolling, or repeated unconstructive feedback.
- Publishing private or sensitive information without permission.

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and other project spaces.

## Reporting

If you experience or witness behavior that violates this code of conduct, open a private security-style report if appropriate or contact the maintainers through the repository’s designated channels. Maintainers may remove, edit, or reject contributions and interactions that do not align with this standard.
