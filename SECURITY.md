# Security Policy

## Scope

This repository contains teaching examples and lightweight repository automation. It is not distributed as production software, but we still want responsible disclosure for security issues affecting the repository, its automation, or published guidance.

## Reporting A Vulnerability

- Please do not open a public issue for a suspected security problem.
- Instead, contact the maintainers privately with a clear description of the issue, affected files or workflows, and any reproduction steps.
- Include impact and any suggested mitigation if you have them.

## What To Report

- Vulnerabilities in repository automation or scripts.
- Sensitive information accidentally committed to the repository.
- Dependency or workflow issues that could affect contributors or users of the repository content.

## What Not To Expect

- Formal SLAs or a bug bounty program.
- Production-grade support commitments for the example models themselves.

We will triage reports in good faith and aim to address confirmed issues promptly.
